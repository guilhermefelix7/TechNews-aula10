# 📱 TechNews Today

## 📌 Sobre o projeto

O **TechNews Today** é uma página de notícias sobre tecnologia desenvolvida utilizando **HTML5 e CSS3**.

O projeto foi criado para praticar a utilização de **HTML semântico** e a estilização de uma página utilizando **CSS externo**.

## 🎯 Objetivo

O objetivo do projeto é criar um portal simples de notícias sobre tecnologia, utilizando diferentes elementos do HTML, como:

- Cabeçalho
- Notícia em destaque
- Data da notícia
- Conteúdo expansível
- Vídeo do YouTube
- Formulário de Newsletter
- Rodapé

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Visual Studio Code
